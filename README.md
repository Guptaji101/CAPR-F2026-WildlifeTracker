## About
A map-based web app that makes global biodiversity data from GBIF locally
relevant and accessible to non-specialists.

## Tech Stack
- Frontend: HTML, CSS, JavaScript, Leaflet.js + OpenStreetMap
- Backend: PHP
- Database: MySQL (XAMPP local)
- Data source: GBIF Occurrence API
